==========================================================
 邻家账本 · 打包成 APK 并安装到小米手机的完整操作步骤
==========================================================

【第 0 步：把整个工程文件夹拷到你自己的电脑】
  把整个「NeighborLedger」文件夹（含子目录）完整复制到你的电脑，
  例如放到 D:\NeighborLedger。注意：
  - 不能只拷单个 .kt 文件，必须整个文件夹一起拷。
  - 路径里尽量不要有中文和空格（例如 D:\NeighborLedger）。

----------------------------------------------------------
【第 1 步：在你电脑上安装编译环境（三选一）】

  方式 A（推荐，最省事）：
  1. 下载并安装 Android Studio（官网 developer.android.com/studio，
     国内可用镜像或直接官网下载）。
  2. 首次启动会让你下载 Android SDK 和 JDK 17，一路下一步即可。
  3. 在 Android Studio 的 SDK Manager 里确认安装了：
     - Android SDK Platform 35
     - Build-Tools 35.x
     - Platform-Tools（含 adb）

  方式 B（命令行，给熟悉命令行的人）：
  1. 安装 JDK 17（设置 JAVA_HOME 环境变量）。
  2. 下载 Android 命令行工具 commandlinetools，装 Android SDK，
     并设置 ANDROID_HOME，指向例如 C:\Android\Sdk。
  3. 用 Gradle 命令构建（见第 2 步方式 B）。

----------------------------------------------------------
【第 2 步：构建 APK】

  方式 A（Android Studio 图形界面，推荐）：
  1. 打开 Android Studio → File → Open → 选择 NeighborLedger 文件夹。
  2. 等右下角 Gradle Sync 完成（第一次会联网下载 Gradle 8.9 和依赖，
     耐心等几分钟；下载完以后就很快了）。
  3. 菜单 Build → Build APK(s)（或 Build Bundle(s)/APK(s) → Build APK）。
  4. 完成后右下角会弹出提示，点 “locate” 找到 APK，路径通常是：
        NeighborLedger\app\build\outputs\apk\debug\app-debug.apk
  5. 这个 app-debug.apk 就是可以直接装的安装包。

  方式 B（命令行）：
  1. 打开 PowerShell / CMD，cd 到 NeighborLedger 目录。
  2. 首次如无 wrapper，先执行：
        gradle wrapper --gradle-version 8.9
  3. 然后执行（Windows）：
        .\gradlew.bat assembleDebug
     （Mac/Linux 用 ./gradlew assembleDebug）
  4. APK 同样在 app\build\outputs\apk\debug\app-debug.apk。

  （如要在别处分发、长期升级，推荐用 Build → Generate Signed App Bundle/APK
    打个签名版 APK；只自用的话 debug 版即可。）

----------------------------------------------------------
【第 3 步：把 APK 发到手机（任选其一）】

  方式 1 - USB + adb（最快，推荐）：
    1. 手机开发者选项 → 打开「USB 调试」，用数据线连电脑。
    2. 电脑上执行：
         adb install -r app-debug.apk
       或（把 APK 复制到手机再手动装）：
         adb push app-debug.apk /sdcard/Download/

  方式 2 - 微信「文件传输助手」/ 网盘 / QQ 发给自己：
    - 把 app-debug.apk 发到手机，下载后点击安装。
    - 注意：App 本身纯本地离线运行，这里只是用传输工具“搬运安装包”，
      与 App 是否联网无关。

  方式 3 - 数据线 U 盘模式：
    - 把 APK 拷进手机存储 Download 目录，用文件管理器点开安装。

----------------------------------------------------------
【第 4 步：在手机上安装（允许“未知来源”）】

  小米 HyperOS 上第一次装会提示“未经安全检测”。操作：
  1. 点击 APK，弹窗提示安装来源时，选择「允许本次安装」
     （或 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 →
       找到你用的“文件管理 / 微信 / 浏览器” → 设为允许）。
  2. 点「继续安装」，装完点「打开」。

----------------------------------------------------------
【第 5 步：小米 HyperOS 首次使用必做 4 件事】

  1) 开「通知使用权」（本 App 的核心，必须开）：
     安装后第一次进 App 会弹引导；
     或手动：设置 → 通知与状态栏 → 通知使用权（或“通知管理 / 读通知”）→
     找到「邻家账本」→ 打开。
     ※ 找不到了就在设置顶部搜索「通知使用权」。

  2) 允许「通知」权限（App 会主动申请，点允许），
     这样超额提醒的通知才能显示。

  3) 关闭电池优化（防止被杀后台）：
     设置 → 省电与电池 → 应用省电策略（或“智能省电”）→
     邻家账本 → 选「不限制」。

  4) 允许自启动 + 后台无限制：
     设置 → 应用设置 → 应用管理 → 邻家账本 →
       ① 权限/自启动管理：打开「自启动」
       ② 省电策略：选「无限制」

----------------------------------------------------------
【第 6 步：验证是否正常】
  1. 打开 App，顶部卡片应显示“今日可用额度 / 今日日限额”等。
  2. 用另一台手机/朋友给自己微信发一笔转账或扫码付一笔，
     微信推送通知后，回到 App 应能看到全新的一条收支记录。
  3. 当日“累计消费”超过“日限额”后再花一笔，会弹出一条本地通知
     （“喂，今天已经超支咯…”），即超额提醒生效。

  （可选）无微信时快速自测，用 adb 发一条模拟微信支付通知：
     adb shell cmd notification post -t "微信支付" \
       "微信支付" "你已成功支付¥25.00，余额剩余¥775.00"
   然后回到 App 看是否解析成一条支出。

----------------------------------------------------------
【常见问题】
  Q：构建报 “SDK location not found”？
  A：File → Settings → Languages & Frameworks → Android SDK 里指定 SDK 路径；
     或在项目根目录新建 local.properties，写入 sdk.dir=C\:\\Android\\Sdk。

  Q：Gradle 同步卡住/下载慢？
  A：正常现象，第一次需联网下载依赖；可配置阿里云镜像加速。

  Q：装完看不到卡片数据？
  A：先去第 5 步开通「通知使用权」，再让微信推一条金额通知。

  Q：数据会不会丢 / 会不会联网？
  A：不会联网、不上传。账单/日志/归档/配置都在 App 私有目录，
     卸载会清空；重装“覆盖升级”（不卸载）不丢数据。
